     kubectl get gateway main -o jsonpath='{.status.conditions[?(@.type=="Programmed")].status}{"\n"}'

Metrics, health and the routing table live on the admin port ({{ (.Values.ports).admin }}) of the
ClusterIP Service {{ include "gapura.fullname" . }}-admin. They are deliberately kept off the
public Service:
     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "gapura.fullname" . }}-admin {{ (.Values.ports).admin }}:{{ (.Values.ports).admin }}
     curl -s localhost:{{ (.Values.ports).admin }}/debug/config | head -20

The GatewayClass {{ (.Values.gatewayClass).name }} is cluster-scoped. A second release of this chart
in the same cluster needs its own gatewayClass.name and controllerName.

The Gateway API CRDs are not part of this chart. Install the standard channel yourself:
     kubectl apply -f https://github.com/kubernetes-sigs/gateway-api/releases/download/v1.6.2/standard-install.yaml
This build is made for the v1.6.2 standard channel. On an older one the API server serves no
backendtlspolicies, the controller logs the absent kind and disables TLS to backends, and
upgrading the CRDs to that channel is picked up within a minute, no restart.
