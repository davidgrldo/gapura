# gapura logo

The mark is a *candi bentar* — the split gate of Javanese and Balinese temples,
which is what "gapura" names — set in a hexagon. The gap between the two halves
is the point: traffic passes through the gate. The hexagon is the shape
Kubernetes tooling is drawn in.

| File | Use |
| --- | --- |
| `gapura-mark.svg` | The mark on its own: avatars, favicons, anywhere the name is already nearby |
| `gapura-lockup.svg` | Mark and name together, on a light background |
| `gapura-lockup-reversed.svg` | The same on a dark background |
| `gapura-mark-mono.svg`, `gapura-lockup-mono.svg` | One colour, inherited from `currentColor`: print, embroidery, a terminal's palette |
| `gapura-mark-{512,180,32}.png` | Social preview, apple-touch-icon, favicon |

## Colours

| | Hex | Why |
| --- | --- | --- |
| Rust | `#C2410C` | The language, and the colour of temple brick |
| Stone | `#1C1917` | The wordmark on light backgrounds |
| Sand | `#FAFAF9` | The wordmark on dark backgrounds |

## Rules

Leave clear space of at least half the mark's height on every side. Do not set
the mark below 16 px, where the gate closes up and it reads as a plain hexagon.
Do not recolour, stretch, rotate, add effects, or set the mark on a busy
background.

The wordmark is Fira Code Bold converted to outlines, so it needs no font
installed. Fira Code is licensed under the SIL Open Font License 1.1.
